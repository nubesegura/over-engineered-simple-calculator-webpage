## Getting Started

This project is a Flutter application that supports both Web and Windows Desktop platforms.

### Windows Desktop Version

To run the application locally on Windows without depending on cloud infrastructure:
1. Ensure you have the Windows development tools for Flutter installed (`flutter config --enable-windows-desktop`).
2. Run `flutter run -d windows` from this directory.
